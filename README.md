               # Виджет личного кабинета клиента
## Описание
Проект "Виджет личного кабинета клиента" - это виджет, который показывает 
несколько последних успешных банковских операций клиента.
## Установка:
1. Клонируйте репозиторий
 ```
   git clone git@github.com:tebras85/PC_home.git
 ```

2. Установите зависимости
```
pip install -r requirements.txt
```

3. Установите библиотеки
```
   pip install requests
```
4. Добавлены тесты для каждой функции в пакет tests
